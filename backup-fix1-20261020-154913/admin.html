Discount rules

Discounts are calculated and saved by the server. Codes do not stack with long-rental offers.

Global automatic long-rental default

Used by vehicles that do not have a custom tier list. This default is 10% and can be enabled or disabled.

Vehicle-specific discount tiers

Custom tiers replace the global default for that vehicle. Only the highest eligible tier applies; discounts never stack.

Each tier has a minimum number of Fiji billable days, a percentage and a maximum FJD discount. Leave custom mode on with no tiers to disable automatic discounts for this vehicle while allowing eligible discount codes.
